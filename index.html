Pengaturan Backup GitHub & Dual-Sync

Konfigurasi auto-backup file backup.json ke repositori GitHub Anda

Token disimpan secara aman hanya di localStorage browser Anda dan tidak pernah ditulis di dalam kode sumber.

Pratinjau Endpoint GitHub REST API https://api.github.com/repos/[USERNAME_GITHUB]/[NAMA_REPO]/contents/backup.json

Skema Tabel Supabase ("data_utama")

Jalankan SQL berikut pada SQL Editor proyek Supabase Anda, lalu isi SUPABASE_URL & SUPABASE_ANON_KEY di bagian atas skrip.

CREATE TABLE IF NOT EXISTS public.data_utama (
  id TEXT PRIMARY KEY,
  tipe_data TEXT NOT NULL CHECK (tipe_data IN ('kader', 'pelatihan', 'kki')),
  payload JSONB NOT NULL,
  updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

ALTER TABLE public.data_utama ENABLE ROW LEVEL SECURITY;

CREATE POLICY "Akses Publik SIKAD" ON public.data_utama
  FOR ALL USING (true) WITH CHECK (true);
